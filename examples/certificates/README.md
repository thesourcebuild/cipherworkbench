# Certificates & mTLS Real-World OpenSSL Verification Examples

This directory provides automated examples and verification scripts that test the cryptographic certificates generated by **CipherWorkbench** (`cert-creator` and `mtls-suite`) against a real **native OpenSSL CLI** installed on your system.

---

## 📂 Architecture: Two Dedicated Runners, Zero Duplicate Logic

All certificate generation, mock server lifecycle, and client connection handling are consolidated into a shared harness (`tls_test_harness.ts`):

```
examples/certificates/
├── tls_test_harness.ts    # Reusable harness (cert creation, server lifecycle, client runner)
├── verify_mock_tls.ts     # Dedicated test for Mock One-Way TLS Server & Client
├── verify_mock_mtls.ts    # Dedicated test for Mock Mutual TLS (mTLS) Server & Client
└── README.md              # Documentation & Run instructions
```

---

## ⚡ Prerequisites

1. **Node.js** (v18+)
2. **OpenSSL** installed and available in your system `PATH` (`openssl version`).
   - Windows: OpenSSL via Git for Windows, Chocolatey, Scoop, or Win64 OpenSSL.
   - macOS: `brew install openssl`
   - Linux: `sudo apt install openssl`

---

## 🚀 How to Run

From the root directory of `cipherworkbench`:

### 1. Run Mock One-Way TLS Test
Starts an OpenSSL mock TLS server and validates client connection with Root CA verification:
```bash
npx tsx examples/certificates/verify_mock_tls.ts
```

**Expected output:**
```text
=================================================
   MOCK ONE-WAY TLS SERVER & CLIENT TEST         
=================================================
Starting OpenSSL mock TLS server on port 9543...
Connecting OpenSSL mock TLS client with CA verification...

✓ PASS: Mock TLS Server & Client Handshake Succeeded!
  - Client verified server certificate against Root CA: OK
  - TLS encrypted tunnel established successfully.
```

---

### 2. Run Mock Mutual TLS (mTLS) Test
Tests both authorized client mutual authentication and unauthorized client rejection:
```bash
npx tsx examples/certificates/verify_mock_mtls.ts
```

**Expected output:**
```text
=================================================
   MOCK MUTUAL TLS (mTLS) SERVER & CLIENT TEST   
=================================================
--- PART 1: Full mTLS Handshake (Client & Server Auth) ---
Starting OpenSSL mock mTLS server on port 9544 with -Verify 1...
Connecting mock mTLS client presenting client.crt + client.key...
✓ PASS: Mutual TLS Handshake Succeeded!
  - Server verified client certificate against Root CA: OK
  - Client verified server certificate against Root CA: OK

--- PART 2: mTLS Enforcement (Reject Missing Client Cert) ---
Starting OpenSSL mock mTLS server on port 9545 requiring client cert...
Connecting client WITHOUT client certificate...
✓ PASS: Mock mTLS server strictly rejected unauthenticated client!
```

## 🖥 Manual Interactive Testing with OpenSSL

If you export the suite using the **Export** button in CipherWorkbench, you can also run live interactive tests directly in your terminal:

**Terminal 1 (Mock mTLS Server):**
```bash
openssl s_server -key server.key -cert server.crt -CAfile ca.crt -Verify 1 -port 8443
```

**Terminal 2 (Mock mTLS Client):**
```bash
openssl s_client -connect localhost:8443 -cert client.crt -key client.key -CAfile ca.crt
```
*(Once connected, anything typed in Terminal 2 will be sent across the mTLS encrypted tunnel to Terminal 1!)*
